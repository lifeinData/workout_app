This almost always means the page was opened directly from the filesystem (file://), which browsers block from reading local files.

Fix — serve this folder over HTTP:

cd "C:/Python Projects/react_native_projects/workout_app/docuemntation"
python -m http.server 8080

Then open http://localhost:8080/.

You can also just read the .md files in VS Code with Ctrl+Shift+V — the diagrams render there too.
